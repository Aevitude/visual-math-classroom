# 禁令对照

模型一听到「课件」就会召回「智能教育平台」。下面这些出现任何一项，先改再交。

| 禁止（出现即失败） | 改成 |
|---|---|
| 🐔🐰🕯️💧 当主体 | 手绘 SVG（几何即可，要有体积和一点性格） |
| 紫/靛渐变英雄区、玻璃拟态后台 | 纸墨或黄昏墨底，一种强调色 |
| 「智能互动课堂」「AI 数学实验室」 | 题名本身：鸡兔同笼 / 蜡烛燃烧 |
| 只有讲解，没有探索 | 四模式齐，探索是默认入口 |
| 主控件乱借：蜡烛用加减只数，鸡兔用时间轴 | 主控件 = 本族主变量 |
| 旁白里手写「4 小时」「24 cm」 | `${S.tEqual}` / `${P.actors[0].height}` |
| 点「下一步」只揭一段字，舞台不动 | 先动画，后说话 |
| 教学中途切方法，两套 await 抢舞台 | `runToken++`，旧流程 return |
| 闯关随机高和小时，出现负剩余 | 先抽整数答案再反推 |
| Alert / 弹窗报「恭喜答对」 | 计量变绿 + 轻庆祝 + 答案卡 |
| 长页滚动、顶栏巨大、底部还一排分享按钮 | 桌面一屏，投屏优先 |
| 动物/蜡烛不会动 | 闲时微动 + 状态变化有动画 |
| 三种方法三种答案 | 全部汇到 `SOLVE` 同一组数 |
| Inter + 圆角卡片堆 + 彩虹标签 | 宋/黑 + Fraunces，卡片不超过三种角色（题、控、师） |

## 自我嗅探

写完用编辑器搜：

- `🎉 ✨ 🐔 🐰 🕯️` → 删
- `#7c3aed` `#8b5cf6` `#667eea` 以及 `linear-gradient(135deg` 大面积使用 → 删
- `typewriter(\`` 里的阿拉伯数字 → 必须能指回 P/S
- `alert(` `confirm(` → 删
- 「下一步」作为按钮唯一文案 → 改成悬念

金样里也有渐变，但只用于纸面的一点暖光和老师卡片的暗角。那是气味，不是主色。不要学成彩虹。
