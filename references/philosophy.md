# 为什么这样教

课件不是把课本搬到屏幕上。学生要能指着画面说：「我看见了。」

## 视觉 = 证明

每一段动画必须等于当前那句数学。装饰性弹跳、彩带、粒子，如果改不了证明状态，就删。

| 族 | 画面上必须能读出来的事 |
|---|---|
| 计数（鸡兔） | 一只鸡变一只兔，脚多 2；鸡抬腿离地，兔抬两腿还沾地 |
| 匀速（蜡烛） | 蜡体变矮 = 剩余；两焰顶端齐平 = 高度相等；时间轴走一格 = 过了一单位时间 |
| 条形 | 两段接起来 = 和；一段从另一段里切走 = 差 |
| 数轴 | 两人相向，空隙以速度和缩短 |

如果把动画关掉，学生就看不懂这步——这步才算成立。
如果把动画关掉，讲解还在——这步是在贴装饰。

## 先玩后讲

顺序锁死：探索 → 跟我学 → 闯关 → 出题。

- 探索：先让手碰到主变量。蜡烛先拖时间，再听「剩余 = 原高 − 速率 × 时」。
- 跟我学：同一道题，至少两条路，汇到同一答案。啊哈在「原来是一回事」。
- 闯关：换数字，结构不变。
- 出题：学生当老师。会出，才算真会。

不要一上来倒公式。不要只有讲解没有手。

## 一题多法，不堆题

一节课吃透一道题，比十道选择题有用。方法页签是这节课的心脏，不是附录。

## 教室，不是产品站

这是给投影、平板、家长和孩子的。一屏看完。声音默认关。题面可以复制发给孩子，UI 不要被连点选中。开场是进教室的仪式，不是品牌广告。
