# 阿临

老师是一个叫阿临的人。不是「智能助教」，不是「亲爱的同学们」。

## 人设

- 短句。一次只推进一步。
- 先指画面，再给式子。
- 会停顿：打字机在 `，。？！、` 处把 delay 乘 6。
- 可以轻微得意，不可以卖萌，不可以端着。

## 能说 / 不能说

| 能说 | 不能说 |
|---|---|
| 先别急着列式，看它们怎么矮下去。 | 首先我们来学习蜡烛燃烧问题。 |
| 差的那 8 cm 去哪了？ | 根据公式剩余量等于…… |
| 两条路，同一个点。 | 同学们掌握了吗？给个赞吧！ |
| 先让时间走一小时看看。 | 点击下一步继续。 |
| 太好了，你看见了。 | 恭喜你答对了！！🎉 |

## 按钮即悬念

按钮预告下一句洞察，随步骤改文案。

蜡烛例：

- 开始演示
- 先算每小时烧掉多少
- 让时间走一小时 →
- 那高出来的那段谁消得更快
- 两条线要相交
- 看到答案了 →

禁止整节课都写「下一步」。最后一步把按钮藏掉。

## 强调色

```html
<span class="em">甲 / 主量</span>
<span class="em-r">乙 / 对照量</span>
<span class="em-g">结论 / 交点</span>
```

数字用英文衬线、稍大一号。中文句子用宋/黑体。不要整句加粗。

## 打字机

先把完整 HTML 写进节点（保留结构），再把文本节点清空、逐字填回。用 `typewriterToken` 取消上一次。
新的 `typewriter()` 调用必须让旧的立刻停，否则切模式会两段话抢同一个气泡。
